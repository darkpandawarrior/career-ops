# Portfolio site

A self-contained Vite + React + Tailwind personal portfolio with an optional AI
chat. The content in `src/data/profile.ts` is generated by HireSignal / career-ops
from your CV — edit it freely.

```bash
npm install
npm run dev          # local preview
npm run build        # production build → dist/
```

**AI chat (optional):** copy `.env.local.example` → `.env.local`, set any one API key
(Groq / Gemini / Anthropic). Without a key the chat shows a contact fallback. The
chat runs as a serverless function (`api/chat.ts`) — deploy to Vercel/Netlify for it
to work; on a static host (GitHub Pages) point `VITE_CHAT_API_URL` at a deployed
function.


## One-click deploy

[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start)
[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new)

`netlify.toml` and `vercel.json` are included (build → `dist`, the chat as a function). Set an API key in the host's env vars for the AI chat.

**Static deploy:** `dist/` is a static site (Netlify Drop / GitHub Pages / any host). For the
chat, deploy the whole project to Vercel (`vercel deploy`) or Netlify.
